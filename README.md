# Resumen para el 2.º parcial · Programación IV

Sitio de estudio para el examen teórico del 2.º parcial de Programación IV (seguridad informática). Resume los informes del trabajo práctico: cada tema tiene la teoría corta, el código explicado (versión vulnerable y protegida), ejemplos y un examen de práctica.

## Contenido

| N.º | Página | Tema |
|---|---|---|
| 01 | `modulo1_sesiones.html` | Variables de sesión |
| 02 | `modulo2_contrasenas.html` | Almacenamiento seguro de contraseñas |
| 03 | `modulo3_fuerza_bruta.html` | Fuerza bruta |
| 04 | `modulo4_recuperacion.html` | Recuperación segura de contraseñas |
| 05 | `modulo5_xss.html` | Inyección de scripts (XSS) |
| 06 | `modulo6_inyeccion_sql.html` | Inyección SQL |
| 07 | `examen_final.html` | Examen final: 42 preguntas al azar de los 6 temas |

## Cómo usarlo

- Abrir `index.html` con doble clic (funciona sin conexión), o entrar a la dirección de GitHub Pages del repositorio `resumen-parcial-prog4`.
- En cada módulo: leer "Lo esencial", los conceptos y el código, y al final hacer el examen. Al elegir una opción se muestra por qué está bien o mal.
- El examen final da la nota y los aciertos por tema, y permite repasar solo las preguntas falladas.

Hecho con HTML, CSS y JavaScript, sin librerías.
